# AionCore 测试范围

新增或修改业务逻辑、端点、WebSocket 或集成测试时，只使用下列与变更相关的要求。

- 单元测试按现有 `#[cfg(test)]` 模块组织，集成测试放在 crate 的 `tests/`。数据库优先使用 `init_database_memory()` 和真实内存数据库，只模拟无关外部依赖。
- 新增或修改功能覆盖正常集成路径；认证、消息、Agent 会话、文件传输、WebSocket 等关键路径尤其需要实际集成用例。
- 新端点/业务逻辑覆盖非法输入、缺失资源、未授权/跨用户访问及业务冲突，断言具体错误码或消息。安全测试检查未认证 401、跨用户隔离、CSRF 和敏感字段不泄露；WebSocket 检查事件、结构及接收者权限。
